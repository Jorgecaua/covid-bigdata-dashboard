# 📊 Dashboard de Evolução da COVID-19 no Brasil

Este projeto consiste em uma plataforma de análise de dados para visualizar a evolução da pandemia de COVID-19 nos estados brasileiros. Utilizei tecnologias de **Big Data** para processar grandes volumes de informações e gerar visualizações interativas.

## 🚀 Tecnologias Utilizadas

* **Python 3.12**: Linguagem base do projeto.
* **PySpark**: Processamento distribuído de dados (Big Data).
* **Pandas**: Manipulação e tratamento de dataframes.
* **Dash & Plotly**: Criação do dashboard interativo e gráficos dinâmicos.
* **Ubuntu Linux**: Ambiente de desenvolvimento.

## 💡 O Problema e a Solução

Trabalhar com dados de saúde pública exige performance, especialmente quando lidamos com registros diários de múltiplos estados ao longo de anos. 
A solução foi utilizar o **PySpark** para limpar e agregar os dados de forma eficiente, permitindo que o usuário filtre as informações por estado e período diretamente na interface do dashboard.
